# АСТРОЛЯБІЯ · дизайн-система КАМЕРТОНА

Штабний HUD для середовища підтримки рішень. Відчуття: панель управління космічної 4X-стратегії, якою користується дорослий штаб. Натхнення: граматика інтерфейсів жанру (зрізані кути панелей, кутові дужки-кронштейни, тонкі лінії, латунний акцент на глибокому синьому космосі). Жодних запозичених ассетів: тільки граматика, все намальовано з нуля.

## Чим ця система НЕ є
- Не «дефолтна AI-стилістика»: заборонені кремові й коралові палітри, serif-шрифти, заокруглення понад 4px, теплий беж, "дружні" ілюстрації
- Не стартап-лендінг: заборонені фіолетові градієнти, glassmorphism, емодзі, конфеті, круглі аватарки
- Не дитяча гра: ніякої мультяшності, тіней-бульбашок, стрибучих анімацій

## Опорні принципи
1. Панель = прилад. Кожен блок має зрізані кути (chamfer 10px) і тонку рамку 1px. Активні панелі отримують кутові дужки-кронштейни
2. Цифра ніколи не сама: поруч завжди дельта проти минулого періоду і міні-траєкторія (спарклайн)
3. Епістемічні теги першокласні: ФАКТ / ОЦІНКА / ГІПОТЕЗА і збіг / розбіжність / 1 джерело присутні скрізь, де є твердження
4. Два режими з жорсткою стіною: ХРОНІКА (факти) і ПІСОЧНИЦЯ (моделювання, попереджувальна плашка)
5. Промах показується так само помітно, як влучання: чесний рахунок це фішка, не сором

## UI/UX правила (обовʼязкові)
- Контраст: основний текст на фоні не нижче WCAG AA (перевірено: #E7EEF6 на #060B14 = 15.9:1; #8A9AB8 = 6.9:1)
- Тач-цілі: інтерактивні елементи мінімум 44x44px, відстань між ними мінімум 8px
- Стани для кожного інтерактивного елемента: default / hover / active / focus-visible / disabled. Focus: 2px обвід кольору --a-cyan, ніколи не прибирати outline без заміни
- Сітка відступів: крок 4px (4/8/12/16/20/24/32). Ніяких довільних значень
- Типографічна шкала: 11 / 12.5 / 14 / 17 / 22 / 28. Заголовки секцій: uppercase, letterspacing .14em, колір латуні
- Анімації: 150ms для станів, 500-900ms для переходів даних, easing cubic-bezier(.4,0,.2,1). Поважати prefers-reduced-motion: усі декоративні анімації вимикаються
- Помилки і порожні стани: кожен компонент даних має empty-стан ("даних за період немає") і partial-стан (позначка неповних даних)
- Мова: українська; без довгих тире (коми, двокрапки); мова наслідків, не рекомендацій; без персоналій

## Токени
Джерело правди: tokens/tokens.json і tokens/tokens.css. Кольори:
- Космос: --a-bg #060B14, панель #0B1220, лінії #24354D
- Текст: #E7EEF6 / вторинний #8A9AB8 / приглушений #55688A
- Латунь (заголовки, акцент штабу): #C9A45C
- Циан (активність, фокус, дані): #56C8D8
- Семантика: деструктив #E5604C, конструктив #7FD489, увага #E0B15C

## v2.1: скло поверх карти
Модель застосунку: карта це світ, інтерфейс це скло над ним. Плаваючі вікна і доки
беруть `.a-panel--glass` (проп `glass` у Panel): підкладка `--a-glass-bg`,
`backdrop-filter: blur(--a-glass-blur) saturate(--a-glass-sat)`. Крізь панель видно
розблурений насичений космос, зорі просвічують кольоровими плямами. Подвійна рамка
і сканлайни зберігаються. Без підтримки `backdrop-filter` скло стає непрозорою
панеллю `--a-bg-raised`: контраст тексту не залежить від ефекту.

Правило: скло тільки для шарів, під якими справді є карта. Панель на суцільному
фоні лишається звичайною, інакше ефект читається як брудна прозорість.

## Інвентар компонентів
- Layout: Panel (chamfer + кронштейни + glass), SectionHeader, ModeBanner (chronicle | sandbox), DoctrineFooter
- Tags: StatusTag (fact | assessment | hypothesis), SourceTag (match | conflict | single), DeltaBadge
- Cards: StatCard (метрика + дельта + спарклайн + поріг), TopicRow (ранг, тренд, тон, звірка), CaseCard (життєвий цикл open | answered | closed | festering)
- Gauges: Sparkline, RopeGauge (канат деструктив-конструктив), ScoreBoard (влучання / промахи / відкриті)
- Controls: HudButton (primary | ghost), LeverButton (важіль з очікуваним наслідком), HudNav
