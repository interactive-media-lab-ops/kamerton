# Корпус історичних кейсів

Тека навмисно порожня.

Правила 2 і 6 Спеки F: історичні факти не додаються поза корпусом, а кожна
картка має `verified_by` з іменем людини. Тому виконавець (AI-асистент) історичних
кейсів **не створює**: корпус наповнюють люди з підписом.

Один файл = один `HistoricalCase`, імʼя файлу збігається з `id`.

Перед додаванням прочитайте `docs/KAMERTON_handoff_16.08.2026.md`, ЧАСТИНА 2
(Спека F «ПРЕЦЕДЕНТИ»), розділ 3. Раніше тут стояло посилання на
`KAMERTON_SPEC_F_precedents.md`, якого в репо ніколи не було: спека жила лише в
транскрипті сесії. Пакет передачі дозволяє розкласти спеки окремими файлами,
але другої копії свідомо не заведено: дві копії правил розходяться мовчки.
Валідатор (`npm run check:corpus`) не пропустить кейс, у якого:

* менше двох джерел;
* усі джерела якості 3;
* немає `verified_by`;
* у `timeline[]` є подія без `phase`.
